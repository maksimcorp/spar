# Changelog

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## Unreleased

Unreleased changes are tracked as per-ticket fragments in
[`changelog.d/`](changelog.d/), one file per ticket. At release time
`scripts/assemble_changelog.py` concatenates them into a dated version section
below and deletes the fragments. Do not edit this file to record unreleased
work; add a `changelog.d/<TICKET-KEY>.md` fragment instead.
